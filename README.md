# SAM AI Technologies — AI Internship Tasks

This repository contains the three completed projects developed during my Artificial Intelligence internship with **SAM AI Technologies**.

## Completed Tasks

### Task 1 — SmartDoc AI
**Intelligent PDF Summarization and Question Answering**

SmartDoc AI is an intelligent PDF assistant that can:

- Upload and process PDF documents
- Extract PDF text using PyPDF
- Generate document summaries
- Perform semantic search using sentence embeddings
- Retrieve relevant document sections using FAISS
- Answer questions using transformer-based question answering
- Display source-page information
- Show supporting context and model confidence
- Detect unsupported questions
- Maintain question-and-answer history

**GitHub Repository:**  
https://github.com/Kaunaingul-ai/SmartDoc-AI

---

### Task 2 — VisionGuard AI
**Object Detection and Image Analysis**

VisionGuard AI is a computer vision application that can:

- Upload images
- Detect common objects using pretrained YOLOv8
- Display bounding boxes
- Show class labels and confidence scores
- Adjust the confidence threshold
- Display total detected objects
- Show unique object types
- Provide object-count summaries
- Display a detailed detection table
- Download annotated detection results

**GitHub Repository:**  
https://github.com/Kaunaingul-ai/VisionGuard-AI

---

### Task 3 — TruthLens AI
**Machine Learning Fake News Classification**

TruthLens AI is a machine-learning application that classifies supplied news text as Real or Fake using:

- Natural Language Processing
- Text preprocessing
- TF-IDF feature extraction
- Logistic Regression
- Real/Fake class probabilities
- Prediction confidence
- Model evaluation metrics
- Confusion matrix

The model was trained and evaluated using the ISOT Fake News Dataset.

Held-out test performance:

- Accuracy: 99.14%
- Precision: 99.41%
- Recall: 98.72%
- F1-score: 99.06%

**GitHub Repository:**  
https://github.com/Kaunaingul-ai/TruthLens-AI
